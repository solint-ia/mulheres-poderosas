# Dia das Mulheres Poderosas

Landing page oficial do evento **Dia das Mulheres Poderosas** — Empreendedorismo Feminino 360°.

## Tecnologias

- **Framework**: Next.js 15 (App Router, Webpack)
- **Estilização**: Tailwind CSS v4 + Vanilla CSS
- **Animações**: Framer Motion
- **Plataforma de Ingressos**: Integrado com Sympla

## Como Rodar Localmente

1. Instalar dependências:
   ```bash
   npm install
   ```

2. Iniciar servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

3. Gerar build de produção:
   ```bash
   npm run build
   ```
